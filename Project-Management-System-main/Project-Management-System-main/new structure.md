new structure

team leader creates account 
leader adds project and gets a project id
other members create their own accounts and join the project using the project id
team leader must approve or reject join requests of the members
team leader is the only one to submit the project links 
every time a student creates a new account he will get a choice to either add a project or join an existing one using project id 
leader chooses their preference for a mentor 
admin can see all the students, their projects, all of the mentors and the projects assigned to them 
admin will see all of the unassigned projects and decide which mentor to be assigned for the specific project 
also all of the mentor accounts will be created by the admin and provided to the mentors 
one student should be in only one ongoing project 
no student can join multiple ongoing projects at once 
but after the project is already submitted and accepted by the mentor the student will be allowed to join other projects 
any student can be a team leader for any project i.e. if a studentr was just a member for one project in their next project they can add their own project and be a team leader
so we dont really have differant roles for members and a team leader all must come under the student category but the creator will get leader permissions only for that specific project
